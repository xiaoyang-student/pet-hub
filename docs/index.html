为什么它不会骗你

市面上大多数"AI 状态"是猜的。PetHub 只做一件事：读应用自己写下来的东西。

📖读真实记录

直接读各软件落盘的 trace span、SQLite 会话库、引擎日志与事件流， 而不是靠"进程还在不在"去猜。

🚫读不到就不说

没有信号时它只讲客观事实，例如"Qoder 已经 7 分钟没有新消息了"， 绝不替你推断成"它在等你"。

🔒纯本地不联网

所有通信都在本机 127.0.0.1。不采集聊天正文，不读你的文件， 不需要管理员权限。

🗂️一行一软件

同一个会话的多轮问答合并成一行；完成后 60 秒自动退场，不会永远挂着"在办公"。

📦免安装依赖

安装包自带 Python 3.13 运行时，双击即用，不读系统 PATH、不污染环境。

🧭装哪儿都能找到

不写死任何盘符：运行时枚举本机真实硬盘，正在运行的软件直接从进程定位安装位置。

常见问题

会不会拖慢电脑？

常驻约 60–90 MB。只在有动画时重绘，没有整屏扫描、没有 OCR。追踪器每 10 秒读一次增量。

我的聊天内容会被上传吗？

不会。全程只在本机回环 127.0.0.1:8765 通信，不联网、不采集正文， 只接收"谁 / 在做什么 / 状态 / 百分比"这类元信息。代码开源，可自行审计。

我常用的 AI 不在名单里怎么办？

来 GitHub 提个 Issue 说明它把数据存在哪儿，我评估适配；也会写怎么自己加适配器。 已知可行的是读它的本地日志或数据库。

卸载干净吗？

干净。卸载会停任务、删文件、清注册表与自启项、移除 MCP 注册，不动你其它软件的环境。 每个版本还留了 backup 分支可回退。
