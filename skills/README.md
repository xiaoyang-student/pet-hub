# PetHub Skills / 桌宠上报技能

Teach your AI agent to report task progress to the PetHub desktop pet.
教你的 AI 智能体把任务进度上报给 PetHub 桌宠。

| Language | File |
|---|---|
| 简体中文 | [`zh-CN/SKILL.md`](zh-CN/SKILL.md) |
| English | [`en/SKILL.md`](en/SKILL.md) |

Install (中文环境): 运行 `installer/install.ps1`，脚本会把 `zh-CN/SKILL.md` 装到 `~/.workbuddy/skills/pethub-notify/`。
Install (English): copy `en/SKILL.md` to `~/.workbuddy/skills/pethub-notify/SKILL.md` manually, or adapt `installer/install.ps1`.

Both versions describe the same CLI (`connectors/pethub.py`) and MCP tools — pick the language that matches your agent's working language.
两个版本对应同一套 CLI 与 MCP 工具，按智能体的工作语言任选其一。
