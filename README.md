## 1. 安装

**方式一：Windows 安装器（推荐）** —— 下载 `PetHub-Setup.exe`，**双击运行**即可，全程图形界面：

- 可自选安装目录、勾选「桌面快捷方式」「开机自动启动」，带进度条；
- 装完桌面 + 开始菜单都有入口，安装目录里放了一个「卸载 PetHub.cmd」；
- 不带参数运行 = 图形向导；也可以命令行静默安装（批量部署、重装时用）：

```powershell
PetHub-Setup.exe                                        # 图形向导，双击也是这个
PetHub-Setup.exe --silent --dir="D:\Apps\PetHub"       # 静默装到指定目录
PetHub-Setup.exe --silent --dir="D:\Apps\PetHub" --autostart
```

不加 `--dir` 时默认装到 `%LOCALAPPDATA%\PetHub`。不需要管理员权限。

**方式二：安装脚本** —— 想自己决定装哪些东西（MCP 服务、上报技能）时用：

```powershell
# 在 installer 目录下
powershell -ExecutionPolicy Bypass -File install.ps1
```

脚本会做五件事：装到 `%LOCALAPPDATA%\PetHub`、注册 MCP 工具服务、安装 `pethub-notify` 技能、开机自启、桌面快捷方式。
可选参数：`-NoAutoStart`（不自启）、`-NoShortcut`（不要快捷方式）。

卸载：

```powershell
powershell -ExecutionPolicy Bypass -File uninstall.ps1          # 保留宠物存档
powershell -ExecutionPolicy Bypass -File uninstall.ps1 -Purge   # 连存档一起删
```

**依赖：什么都不用装。** 安装包自带一份 Python 3.13 运行时（`runtime\python\`），
桥接、「导入应用」观察器、MCP 服务全部用它，不读系统 PATH、不需要管理员权限、不污染系统环境。
唯一需要的是 **WebView2 运行时**（Win10 1803+ / Win11 随 Edge 自带）；
万一没有，安装时会**自动下载并静默安装**（约 1 分钟，需联网），装不上会在最后弹窗明确告诉你。

装完之后目录长这样（92 MB 左右）：

```
PetHubLight.exe          壳层（自带 .NET，单文件）
runtime\python\         自带的 Python，别删
bridge\                  桥接服务
connectors\              MCP / CLI / 通用观察器
app\                     宠物页面
```

**想让它退出时**：托盘右键 →「退出」，或者 `PetHubLight.exe --quit`。
后者会把桥接进程一起收掉，不留后台残留——卸载脚本走的就是这条路，
因为直接 `taskkill /F` 会在通知区留下点不动的"幽灵图标"。

## 2. 目录结构

```
pet-hub/
├─ app/index.html          宠物本体（画面、宠物、HUD、全部交互逻辑）
├─ bridge/server.py        桥接服务（127.0.0.1:8765，收事件、转发给桌宠）
├─ connectors/             接入工具集
│   ├─ pethub.py           命令行：安装/卸载接入、状态、一行上报
│   ├─ pethub_mcp.py       MCP 工具服务（推荐，任何支持 MCP 的客户端都能调）
│   ├─ universal_hook.py   通用 Hook 脚本（Claude Code / WorkBuddy / Qoder 等）
│   ├─ observer.py         零接入观察器（进程与文件活动，兜底用）
│   └─ ...                 其它平台适配
├─ light/                  Windows 壳层（.NET 10 + WebView2，负责透明与点击穿透）
├─ installer/              install.ps1 / uninstall.ps1 / skill
└─ README.md / README.en.md
```

启动顺序：先跑桥接（`python bridge/server.py`），再启动 `PetHubLight.exe`。壳层检测不到桥接时会自己拉起它。

## 3. 五种接入方式（任选）

设计原则：**让应用自己说**，而不是我们去猜它在干什么。

### ① MCP 工具（推荐）

安装脚本已把它注册进各家配置（`~/.workbuddy/mcp.json`、`~/.qoder/mcp.json` 等），服务名 `pethub`。
支持 MCP 的客户端可以直接调用：

| 工具 | 用途 |
|---|---|
| `pethub_report` | 上报状态 `running / thinking / waiting / done / error` |
| `pethub_ask` | **真实事件**：我在问用户、要授权、要拍板 |
| `pethub_done` | 标记完成（宠物心情 +3） |
| `pethub_remove` | 移除任务 |
| `pethub_state` | 查询桌宠当前显示的任务 |

### ② 命令行（脚本 / CI / 任何应用一行调用）

```bash
python connectors/pethub.py say "正在重构登录模块" --platform Qoder --status running --progress 40
python connectors/pethub.py say "是否允许删除 build/" --platform Qoder --ask     # 要授权
python connectors/pethub.py say "重构完成" --platform Qoder --done
```

### ③ Hook（Claude Code / WorkBuddy / Qoder 等）

```bash
python connectors/pethub.py list          # 看本机有哪些可接入平台
python connectors/pethub.py install auto  # 自动接入所有识别到的平台
python connectors/pethub.py remove <名字>
```

### ④ HTTP 接口（任何能发 POST 的东西，AI 办公软件走这条）

```bash
curl.exe --noproxy "*" -s -X POST http://127.0.0.1:8765/api/events \
  -H "Content-Type: application/json" \
  -d "{\"platform\":\"豆包\",\"task_id\":\"job-1\",\"title\":\"写周报\",\"status\":\"running\",\"progress\":30}"
```

字段只有六个：`platform`（谁在干活）、`task_id`（固定 ID，重复 POST 就是更新同一条）、`title`、
`status`（`running / thinking / waiting / done / error`）、`progress`（0-100，可省）、`message`。
整批同步用 `{"type":"sync","tasks":[...]}`；删除用 `{"type":"remove","task_id":"..."}`。

> **三个坑，踩了会以为接口坏了**
> - 写 `curl.exe`，别写 `curl`：PowerShell 里 `curl` 是 `Invoke-WebRequest` 的别名，参数全不认。
> - `--noproxy "*"` 不能省：开着 Clash / V2Ray 时，发往 127.0.0.1 的请求会被代理转走，返回 502。
> - PowerShell 5.1 会把 JSON 里的双引号吞掉（`{"a":"b"}` 变成 `{a:b}`），报
>   `Expecting property name enclosed in double quotes`。服务端已做容错，照抄上面的命令也能通；
>   想严格就用单引号包 JSON：`-d '{"platform":"..."}'`。

**不想自己拼？** 托盘右键 →「给 AI 软件接入…」：里面有一段**可以直接粘给豆包 / 百度搭子 / ChatGPT
的提示词**、一条现成命令、MCP 配置，外加一个「发一条测试」按钮——点一下宠物立刻开口，通没通一眼就知道。

接口自述也放在本机：`GET /api/help`（JSON，给 AI 读）、`http://127.0.0.1:8765/help`（网页，给人看）。

### ⑤ 导入应用（豆包、百度搭子这类不开放接口的软件）

先说清楚一件事：豆包、百度搭子、ChatGPT 桌面版这些**不提供本地插件 / MCP 入口**，所以不存在"把连接器装进它里面"这回事——它们跑什么、跑到哪一步，外部拿不到。

那就反过来：**PetHub 从外面盯着它**。

托盘图标 → `接入应用…` → 选它的 exe（可多选）。**一次点击就到文件选择框**，没有二级菜单。之后零配置：

| 时机 | 会发生什么 |
|---|---|
| 软件刚启动 / CPU 明显在动 / 窗口标题变了 | 任务立刻出现在托盘和面板上，标题 = 「应用名 · 当前窗口标题」 |
| 连续 22 秒没动静 | 转成"已完成" |
| 再安静 1 分钟 | 从列表撤掉，不占位 |
| 软件被关掉 | 任务直接消失，不会谎报"还在跑" |

判据只有三样：**进程在不在、CPU 动没动、窗口标题变没变**。所以任何软件都能接，代价是拿不到精确百分比——想要「40%、等你确认」这种粒度，仍然得让应用自己说（用 ①②④）。

名单存在 `%LOCALAPPDATA%\PetHub\apps.json`；脚本或安装器可以静默导入：

```bash
PetHubLight.exe --watch-app "C:\Program Files\Doubao\Doubao.exe"
```

托盘里「已接入 N 个」可以随时启用 / 停用 / 清空名单，不影响桌宠本身。

**不会和软件自己上报的重复。** Qoder、WorkBuddy、Cursor 这类既能被外部观察、又有 hook / MCP 在报的软件，
桥接会自动收敛：只要它自己报了（哪怕后到），「应用接入」那条粗粒度的就被撤掉，只留精确的那条。
判据是"软件名"双向包含（`workbuddy.exe` ↔ `workbuddy`、`qoder.exe` ↔ `qoder`），
所以同一个活不会在面板上出现两行；反过来它自己不报了，粗粒度那条会在下一轮观察（2 秒）补回来。

### 真实性规则（重要）

- **"要授权 / 卡住了"只认应用亲口上报**（`pethub_ask`、`--ask`、或 hook 带 `ask` 标记）。
- 没有任何信号时，宠物只会说客观事实，例如「Qoder 已经 7 分钟没有新消息了」，**不会**推断成"在等你"。
- 任务超过 **30 分钟**没有新事件会被当作失联自动移除，避免"应用早关了还说在跑"。

## 4. 日常使用

| 操作 | 效果 |
|---|---|
| 左键宠物 | 互动、说话 |
| 右键宠物 | 菜单：喂食 / 抚摸 / 玩耍 / 清洁 / 睡觉 / 看病 / 切语言（就这些，不再往里堆）。**有多只时，菜单作用于你右键的那一只**；只有 1 只时才多出「🐾 换宠物」 |
| 双击宠物 | 切换前后层：**置顶层** ↔ **桌面层** |
| 点地上的粑粑 | 直接扫掉，不用再从菜单里点「清理」 |
| 把宠物拖到屏幕边缘外松手 | 它离家出走，**不会再回来** |
| 把宠物**拎到屏幕最上面**松手 | 它抓住天花板，蹭两下再顺着墙慢慢爬下来 |
| 再点一次桌面快捷方式 | **再来一只**（最多 6 只，任务栏始终只有一个图标） |
| 点 HUD 里的任务 | 宠物复述这条任务 |
| 拖 HUD 标题栏 | 挪位置 |
| 点「收起 ▸」 | 收成一个小爪子图标（图案跟着当前宠物变） |
| 左键单击通知区圆标 | 展开 / 收起任务面板 |
| 右键通知区圆标 | 任务清单 + `接入应用…`（选个 exe 就接入）+ `给 AI 软件接入…`（提示词 / 自检）+ 显示桌宠 / 切前后层 / 退出 |

**语言**：右键 → `🌐 中文 / English`。UI、状态、宠物台词、气泡落款**同时切换**，不会一半中一半英；选择会记住。

**养宠物的一天**：清晨精神、午后犯困、深夜自己睡觉打呼；白天饿得快、夜里代谢慢；早上 6–9 点说早安并自动起床，23 点说晚安。数值只有 5 个：饱腹 / 体力 / 心情 / 卫生 / 健康。

**离线记忆**：关机后第二天回来，会按真实离开时长结算——饿了、心情掉了、还攒了几处排泄物，并弹出「你不在的 N 小时里」的结算提示。最多结算 12 小时，不会"饿死"。

**时间感与贴心关怀**：开机和每个整点会报日期、星期、几点，并说一句应景的话（周一早上、周五晚上、午饭点、深夜催睡……）；还会记住**安装第几天**（第 7/30/100/365 天有纪念台词）。壳层每 3 秒记一次前台应用时长（开销可忽略），超过 45 分钟会提醒你休息、喝水、看看远处，且**每 25 分钟最多说一次**，不啰嗦。

### 任务栏：把宠物收起来也看得见

通知区常驻一个小圆标，它是"宠物"和"任务"之间的中转站：

| 圆标 | 含义 |
|---|---|
| 灰环 + 小点 | 空闲 |
| 蓝环 + 数字 | 有几件任务在跑 |
| 琥珀环 + 数字 | 有任务**在等你确认** |
| 红环 + 数字 | 有任务出错 |

- **悬停**：`PetHub · 进行中 2`，第二行是当前任务名和进度
- **左键单击**：展开 / 收起任务面板（等同于点 HUD 的「收起」）
- **右键**：任务清单（点任意一条，宠物把它念出来）、`接入应用…`（把豆包这类软件导进来）、`给 AI 软件接入…`（复制提示词 / 发测试）、显示/收起桌宠、切前后层、退出
- **图标不会重复出现**：状态组合固定，图标句柄全程复用，不再出现 2~3 个残影（详见第 8 节）
- **等你确认时自动弹通知**，不用一直盯着屏幕（20 秒内最多一次，不刷屏）

> **Windows 11 第一次会把它折进 `^` 里。** 点任务栏的 `^`，把 PetHub 图标拖到任务栏上，以后就固定在那儿了——只需拖一次。第一次运行时程序也会弹一条提示，宠物同时会说一句。

数据是**实时**的：页面从桥接的 SSE 收到任务变化就立刻推给壳层，托盘跟着变；壳层另有 3 秒兜底轮询，页面卡住或还没加载完时接管，保证托盘不会僵在"还在跑"。

## 5. 多只宠物：生命周期与社交

**再来一只**：再点一次桌面快捷方式就行（不用进菜单）。单实例保护仍然生效——第二次启动不会开出第二个全屏窗口，只是给已经在跑的那只发个信号，让页面多生一只。上限 6 只，任务栏永远只有一个图标。

**它们会长大变老**：蛋 → 幼崽（25 分钟）→ 少年 → 成年 → 老年，体型随阶段变化；成年后关系够好会下蛋，孵出小崽；寿命到了会自然离开（会留一句告别）。全部存档，关机重开接着过。

**它们之间会发生什么**（凑近了才触发，一次只演一出）：

| 互动 | 表现 |
|---|---|
| 闻一闻 👃 | 刚认识时先打个招呼，关系 +3 |
| 一起玩 🎵 | 互相追着跑，心情涨、体力掉 |
| 蹭头 ❤️ | 关系够好才有的亲昵动作，感情到位会考虑添丁 |
| 八卦 💬 | 两只一来一回聊一段：吐槽主人、讲冷笑话、数桌面图标…… |
| 吵架 💢 | 你一句我一句，双方心情都掉，关系变差 |
| 打架 💥 | 只有积怨已深或脾气太冲才会动手；**最早出生的那只（老大）永远赢**，输的一方掉心情、掉健康、掉卫生 |

关系是**按宠物对**记的，会存档：处得好的下次见面还亲，结过仇的下次见面还会吵。

**全屏自由行走**：不再被钉在任务栏上，屏幕中间、上半部都能去（会飞会跳的物种上去得更勤）。位置变化是平滑过渡，不会瞬移。

**前后层**：双击宠物切换。
- **置顶层**（默认）：一直在所有窗口上面；
- **桌面层**：压到普通窗口之下、桌面之上——你点开别的应用就看不见它，回到桌面它还在。
  切到桌面层后想叫它出来：`Ctrl + Alt + B`，或者点桌面空白处再双击它。

**出门溜达**：宠物偶尔会自己走到屏幕边上消失一阵（家里至少留一只），回来时会说外面的事；**大约 12% 的概率**会带回来一个新伙伴，还有约三成概率带点小东西。

**每个物种的粑粑都不一样**：猫狗是经典三层锥、兔子是一小堆干球、鸡鸭是白色的一摊、蛇是细长一条、蜘蛛是几粒小黑点。点一下就扫掉，冒几粒灰。

**扔到天花板（Shimeji 玩法）**：把宠物拎到屏幕最上面松手，它会一把抓住顶边、贴着天花板横着蹭两下找落脚点，再**顺着看不见的墙一点点爬下来**，落地才松爪。爬的时候身体会一紧一松地使力，脚下掉墙皮屑。以前拖拽最多只能拎起 280px，够不到天花板，所以这个动作根本做不出来——现在能一路拎到顶。

**偷偷叼走鼠标指针**：它偶尔会趁你半天没动鼠标，蹑手蹑脚走到指针旁边，一口叼住，把指针拖到自己嘴边带着走几秒，然后放下。

规矩定得很死，不会真的抢你的鼠标：
- 连续 **20 秒**没碰鼠标才动手，4~10 分钟最多一次；
- 指针在屏幕上半部它够不着，就不去；
- **你一动鼠标、或者随便点一下，它立刻松口**（壳层收到真实输入就通知页面放人）；
- 全程只是 `SetCursorPos` 把指针挪到它嘴边，不做任何点击。

## 6. 透明与点击（常见问题）

- 桌宠是**全屏透明层**，但**不挡点击**：桌面图标、文件、其它窗口照常可点。
- 只有鼠标真的落在宠物 / HUD / 气泡上时，这一次点击才会被桌宠接走（全局钩子转发）。
- 历史上出现过"整屏挡住点不动"的 bug，有两层根因：
  1. WebView2 会生成一个全屏**子窗口**偷偷吃点击 —— 启动时强制它 `WS_EX_TRANSPARENT`；
  2. WebView2 还会在**浏览器进程**里再开一个铺满全屏的宿主窗口（`Chrome_WidgetWin_1`），它不属于本进程，父窗口穿透对它无效 —— 现在启动时会按进程树找到它并同样补上穿透位，且每 1.5 秒自检一次，被重建也会自动修好。
- **救命热键**（任何时候都能用，不依赖宠物界面）：
  - `Ctrl + Alt + Q` —— 直接退出桌宠；
  - `Ctrl + Alt + H` —— 收起 / 唤出桌宠（收起时会卸掉鼠标钩子，桌面完全干净）；
  - `Ctrl + Alt + B` —— 前后层切换（宠物躲到桌面层看不见时，用它叫回来）。
- 顶部若出现白线：那是旧版画的地面装饰线，已删除；如仍有，重编译壳层即可。

## 7. 性能与隐私

- **不联网**：所有通信都在 `127.0.0.1:8765` 本机回环，桌宠不访问任何外部服务。
- **不采集内容**：只接收"平台名 / 任务名 / 状态 / 进度 / 一句话说明"；不读你的文件、不读聊天正文。
- **Hook 留痕默认关闭**：`universal_hook.py` 里的原始事件落盘需要显式设置 `PETHUB_DUMP=1` 才会开启，因为原始内容可能含隐私。
- **开销**：壳层常驻约 60–90MB；画面 60fps 只在有动画时重绘；前台应用统计每 3 秒一次；命中测试每 30ms 一次且只在鼠标移动时；没有轮询整屏扫描、没有 OCR。

## 8. 故障排查

| 现象 | 处理 |
|---|---|
| HUD 显示"演示模式" | 桥接没起来：运行 `python bridge/server.py` |
| 宠物不动 / 白屏 | 确认 WebView2 运行时存在；看 `%TEMP%\pethub-light.log` |
| 外部应用上报没反应 | 确认桥接在线：`python connectors/pethub.py status` |
| MCP 工具看不到 | 重启客户端让它重新加载 `mcp.json`；确认 Python 在 PATH |
| 想看平台到底送了什么 | `set PETHUB_DUMP=1` 后跑一次任务，看 `~/.pethub-hookdump.log`（**会记录原始内容，用完请关掉并删除**） |
| 通知区出现 2~3 个圆标，过会儿又变回 1 个 | 旧版本每次状态变化都换一个新图标句柄，资源管理器会把它当成新图标，短暂留下残影。现在图标按状态缓存复用、句柄恒定，且 400ms 防抖合批，已不再出现 |
| 导入的应用一直没动静 | 确认它在跑、且菜单里那一项是勾选状态；观察器只认「进程 + CPU + 窗口标题」，全屏独占或后台静默干活的软件可能看起来是闲的 |
